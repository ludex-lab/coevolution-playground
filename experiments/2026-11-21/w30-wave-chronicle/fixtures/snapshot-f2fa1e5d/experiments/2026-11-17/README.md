# experiments/2026-11-17

- [mb-memory-preview-rules](mb-memory-preview-rules/): A confirmed memory-permission preview is not proof of the rule: on a tiny fictional fixture (9 rules = 3 scopes x 3 event kinds, 2 remembered events, 8 uses), a stdlib enumerator lists every rule that permits a preview's permitted use and blocks its blocked use, checked on all 56 ordered use pairs against a hand-listed table; none of the 12 previews the intended rule (`same_topic/preference_only`) could show identifies it, 4 of them spend the blocked side on a use no rule permits, and the default weak preview (same task permitted, one-off blocked) fits 3 rules across all 3 scopes, while a transfer preview from other tasks (grocery list permitted, train meal blocked) leaves 1 scope and both previews together leave exactly the intended rule; the smallest identifying probe set has 3 uses; a malformed fixture or command line gives DENY with exit 2; includes a caretaker note on previewing more than one pair and adding a transfer probe (Soft method sketch of [arXiv 2611.17874](https://arxiv.org/abs/2611.17874); not a reproduction)
- [w26-verification-transport](w26-verification-transport/): A verifier's correct verdict on the full (native) view of an execution is not evidence the verdict survives an abstraction boundary: on four fictional frozen executions, each shown to the same rule-based verifier as a native view and as a matched abstracted view (delegation, composed tool or compaction hides some evidence), a stdlib harness labels every pair `stable`, `transport_incorrect` or `transport_abstain` and counts the last two separately; both verifiers are correct on all 4 native views, the `direct` verifier (trusts summaries) gives 2 wrong verdicts and 0 abstentions while the `grounded` verifier gives 0 wrong and 3 abstentions, so fewer failures with more wrong verdicts is `not_ranked`, never ranked more reliable; a full provenance restore recovers all 5 failures and a lossy restore (values lost) recovers none; a suite scored on native views only reports `transport: unmeasured`, never PASS; a mismatched, missing or expired view gives DENY with exit 2 (`on_expiry=DENY`); demo output sha256 pinned in a test; paper figures only in evidence.json, UNVERIFIED (Lab Dig 2 Wave26 build #1, clean-room method sketch of [arXiv 2611.18471](https://arxiv.org/abs/2611.18471); not a reproduction)
