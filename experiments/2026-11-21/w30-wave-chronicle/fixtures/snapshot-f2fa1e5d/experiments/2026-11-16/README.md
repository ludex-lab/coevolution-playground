# experiments/2026-11-16

- [mb-owned-exceptions](mb-owned-exceptions/): A local exception is not a rule change: on a frozen synthetic rule over 768 items and four parties that each own one subject, an owned, typed (subject, scope, form, size), evidence-gated exception changes decisions only in its owner's block (byte-identical elsewhere, checked for every admission and every live exception of a seeded 400-step sweep), withdraws to the exact prior parameters (equal to a rebuild from scratch, and the same in every admission order), and is refused when ungated, half-gated, forged, below the selection-aware gate, unowned, from an unknown party or mistyped (bool, NaN, inf, subclass keys or values, relaxation forms, sent weights); the base rule's digest never changes, a plain table of owned rows decides identically to the compiled units, and writing one party's declaration into the shared rule instead changes 108 other-party decisions; agrees with an independent oracle on every case, a 7,680-submission space and every sweep state (Soft method sketch of [arXiv 2611.15917](https://arxiv.org/abs/2611.15917); not a reproduction)
- [w25-series-title-lint](w25-series-title-lint/): A stdlib file-in/file-out lint of series labels in video titles against a declared catalog (canonical label per language, number format, retired aliases in order, known variants, optional character names): on the observed @LudexVillage first-page titles it fails `Ludex Weekly06`/`Ludex Weekly05` (spacing), `Ludex Village Doc 07` (label) and `Documentary · Ep. 2` (number format), reports `Naru Daily Weekly 01` and `Ludex Daily Weekly 02` as retired aliases (INFO, not drift), passes the deliberate Korean `다큐 N화` labels, warns on number gaps, fails duplicate numbers, and gives DENY with a non-zero exit for any missing, unreadable or malformed input (Lab Dig 2 Wave25 build #1)
- [w25-daily-issue-index](w25-daily-issue-index/): A stdlib file-in/file-out list check of Naru Daily issues (number, date, EN/KO present) and of the Dailies each annals close names: on the observed site list (83 issues, No. 1-83) it reports No. 82 (11-13) above No. 81 (11-14) as INFO `published_late` and the dates with no issue (08-25, 08-29, 08-31, 11-10) as INFO, so the list alone passes (exit 0); a number named in two closes (Daily 76, 78, 80) is INFO `reissued` and one number counted twice in one close (Daily 74 on Day 91, Daily 78 on Day 94, both same-day reissues in the annals) is INFO `counted_twice`, so the list with the closes also passes (exit 0); one number twice in one index list fails, as do a missing number (also against a declared `--first`/`--last` range), an id/printed mismatch, a missing language body and folded or decorated digits; a missing, unreadable or malformed fixture gives DENY with exit 2; reports facts only, no hashing or signing (Lab Dig 2 Wave25 build #2)
