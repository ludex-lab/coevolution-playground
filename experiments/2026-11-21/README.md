# experiments/2026-11-21

- [mb-evidence-binding](mb-evidence-binding/): frozen synthetic filing with three planted answers per question (correctly bound, scale or unit error whose number string still appears in the cited quote, right line but wrong period); a loose binding test that only asks whether the reported number appears in a cited quote on the cited page passes all three, while a strict binding test that also matches the quote's line, period, unit kind and table scale note accepts only the correct one and rejects the others with distinct reason codes (method sketch of [arXiv 2611.24990](https://arxiv.org/abs/2611.24990); not a reproduction)
- [w30-wave-chronicle](w30-wave-chronicle/): A stdlib file-in/file-out wave chronicle of the experiments index: it turns the `- [slug](slug/): …` rows of the day READMEs dated 2026-11-09 or later into a dated timeline tagged with wave, family and track (an unmapped prefix is INFO `unknown_track`, never an invented track), with counts per day, track, family and wave and an optional what-changed list (added, removed, changed rows) over two snapshots; every entry carries the path and git blob SHA1 of its day README; earlier days use a table layout and are listed as `on_unmeasured: legacy_table_format` without being opened, as are days outside `--from`/`--to`; on a pinned byte-exact snapshot of the 13 real day READMEs at main f2fa1e5d it reports 13 days and 49 entries, and a missing, unreadable, unpinned or malformed in-scope README gives DENY with exit 2 (Lab Dig 2 Wave30 build #1; clean-room, no paper)
