# experiments/2026-11-11

- [w20-plan-change-notice](w20-plan-change-notice/): Acknowledging an objective change is not acting on it: a baseline acks every notice yet goes on executing its cached plan, a notice-first guard checks the plan's objective version before each consequential step and replans or waits to a declared on_expiry, and a detector comparing actions with the authoritative objective separates traces whose ack and completion summaries match (method sketch of [arXiv 2611.10011](https://arxiv.org/abs/2611.10011); not a reproduction)
- [w20-acf-adherence](w20-acf-adherence/): Does an agent do what its context file says? An AGENTS.md-like context file is checked against commits one instruction at a time via operational predicates or not-operationalized markers, with per-commit and batch follow reports and an enforcement hook that refuses commits failing any measured instruction (method sketch of [arXiv 2611.13709](https://arxiv.org/abs/2611.13709); not a reproduction)
- [w20-evidence-linked-memory](w20-evidence-linked-memory/): A lesson is only as good as the run it came from: memory holds linked insight, run summary and trajectory per lesson, and an agent must descend to the trajectory before acting when the insight is incomplete, contested or of doubtful origin; three agents on the same toy tasks compare no memory, insight-only, and the descend rule (method sketch of [arXiv 2611.14320](https://arxiv.org/abs/2611.14320); not a reproduction)
- [w20-fidelity-audit](w20-fidelity-audit/): A tool pass vouches only for the artefact it ran on: toy tools check claims against artefacts with bound digests, audit() re-runs and drops irreproducible results, human judgment is a separate digest-bound record, ambiguous claims are split before acceptance, and dialog reports attribute every step (method sketch of [arXiv 2611.13042](https://arxiv.org/abs/2611.13042); not a reproduction)
- [w20-checkable-rulebook](w20-checkable-rulebook/): A gatekeeper watching a program for finitely many steps can settle that a forbidden event happened but not that one never will or that an answer will come: this sketch issues only what the watched prefix settles—a refusal with the violation position or a certificate scoped to the steps it saw, while standing "never" and "eventually" claims stay UNSETTLED and unanswered waits resolve only through declared on_expiry (Soft method sketch of [arXiv 2611.13367](https://arxiv.org/abs/2611.13367); not a reproduction)
