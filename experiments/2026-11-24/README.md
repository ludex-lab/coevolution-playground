# experiments/2026-11-24

- [mb-zero-reference-pass](mb-zero-reference-pass/): an equivalence pass shows a response only if a zero reference would fail the same check: on hand-made synthetic contrasts, each candidate effect is checked against a human 90 percent interval with a stated margin (inclusive, exact decimals), and the strict arm prints beside every equivalence decision whether an effect of 0 would also pass and the margin at which it would; a reminder-letter contrast passes while zero fails (a response), a font-change contrast passes but zero passes too (labelled as not establishing a response), and a peer-comparison contrast fails, while the weak equivalence-only arm counts 2 of 3 as matches and cannot tell them apart; edge cases cover exact boundaries, a negative effect, fails where zero passes and an interval too wide for any match, and malformed input is DENY with exit 2; candidate uncertainty and the paper's planned-precision margin are left out and no paper number is verified (method sketch of [arXiv 2611.27186](https://arxiv.org/abs/2611.27186); not a reproduction)
- [w33-fold-160-paper-strict-threshold](w33-fold-160-paper-strict-threshold/): a fold of mb-zero-reference-pass, not a new experiment: beside #160's inclusive zero-reference reading (zero passes when the critical value T = max(|human_lo|, |human_hi|) is at most the margin) it prints the paper-strict reading (zero passes only when T is below the margin), so at m = T the zero_on_edge contrast is PASS inclusive and FAIL paper-strict; the strict-arm header is relabelled so no `>=` reads as the paper's `<`, both readings and T are checked on every JSON and report row, #160's crash-only bool mutant and untested unreachable note now die by assertion, the paper's zero-reference condition and its simulation criterion are named separately, exponent extremes are DENY with exit 2 (0E+999999999 included), and no paper number is verified (method sketch of [arXiv 2611.27186](https://arxiv.org/abs/2611.27186); not a reproduction)
