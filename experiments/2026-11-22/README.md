# experiments/2026-11-22

- [mb-verify-the-verifier](mb-verify-the-verifier/): a green scoreboard is not a met specification: on a fixture-authored toy 4-entry FIFO with five numbered spec clauses, a scoreboard that compares the design with a golden model passes three planted escapes (the golden model shares an overwrite-when-full or last-in-first-out bug, or the wrong full flag is never compared), while an independent clause audit that reads only the clauses and the observed trace fails each one with a clause id and reason code; clean cases pass both and real failures fail both; the paper's model-based cross-check is stood in for by a rule-based clause evaluator with no model call, and the planted counts are not model or real-world rates (method sketch of [arXiv 2611.26588](https://arxiv.org/abs/2611.26588); not a reproduction)
- [w31-prerelease-is-not-stable](w31-prerelease-is-not-stable/): a pre-release is not the associated normal version: on fixture-authored {candidate, requirement} pairs, a strict SemVer 2.0.0 parser orders versions by spec §11 precedence, so 1.0.0-alpha and 1.0.0-rc.1 do not satisfy >= 1.0.0 or == 1.0.0, while a declared stable-range policy (not a SemVer rule) also rejects higher-core pre-releases such as 1.0.1-rc.1; a weak strip-the-suffix arm wrongly accepts them and fails the gate, and malformed versions are DENY (clean-room; Semantic Versioning 2.0.0, CC BY 3.0)
