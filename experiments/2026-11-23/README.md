# experiments/2026-11-23

- [mb-occupancy-cap-per-bucket](mb-occupancy-cap-per-bucket/): a burst should not take over a bounded memory: on synthetic village fixtures, a fixed-slot memory takes in timestamped items with salience scores; score-only eviction lets a fireworks burst fill 6 of 6 slots and push out earlier items a later question needs, and plain FIFO loses them too, while a hard per-time-bucket occupancy cap (fixed-duration buckets, at most k slots each, deterministic tie-break) holds every needed item; a calm case passes score-only and the cap while plain FIFO still drops its oldest needed item there; a case with more needed items in one bucket than the cap shows the cap's cost, and malformed input is DENY with exit 2; the paper's secret-key sampler is left out and no paper number is verified (method sketch of [arXiv 2611.25649](https://arxiv.org/abs/2611.25649); not a reproduction)
- [w32-record-manifest-presence](w32-record-manifest-presence/): does a record folder hold every file its cover names: on small hand-made fixtures that mirror the E1 and E2 measurement covers, a stdlib tool reads the cover's `## Files` table, a folder listing and an optional ignore-rule file; each named file or receipt the listing lacks is FAIL, tagged with the ignore rule that explains it (E1 shows 4 misses and E2 shows 2, each explained by the `*.jsonl` rule when the ignore file is given), `{a,b,c}` names expand per file, tokens such as `CORRECTION_01…03` are noted as unparsed rather than counted as misses, names with a space, `@`, `+`, `~`, a leading dot or a folder path are still checked, a Corrections group is optional, and malformed input is DENY with exit 2; it never writes or restores the missing files and does not claim they never existed (clean-room; no network)
