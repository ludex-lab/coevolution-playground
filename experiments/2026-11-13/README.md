# experiments/2026-11-13

- [w22-write-precommit](w22-write-precommit/): Commit writes before any tool result: a pure stdlib check over a fixture event trace admits a write only when its call was committed before the first applied tool result, its tool and every targeting argument (recipient, amount, object, destination; read from the tool schema) are unchanged since that commit, and each targeting argument is a non-blank substring of the user request, so a write injected after a tool result, a precommitted write with an unstated destination or amount, and a precommitted write retargeted after a tool result (even to a target the request also names) are all refused, and an episode that supplies its own policy is config_error (Top method sketch of [arXiv 2611.17115](https://arxiv.org/abs/2611.17115); not a reproduction)
- [mb-creg-belief-scoring](mb-creg-belief-scoring/): Score the whole belief trajectory, not the endpoint: a stdlib log-odds updater reports posterior, support and contradict sets, contradiction flag and an admissible next action after every evidence prefix of a frozen synthetic suite, agrees with an independent Bayes-factor oracle on every prefix, shows a baseline that is right at the endpoint but wrong mid-trajectory, and shows that dropping relation content hurts only the relation-dependent subset; missing on_expiry is config_error and expiry never dispatches (Soft method sketch of [arXiv 2611.11842](https://arxiv.org/abs/2611.11842); not a reproduction)
- [w22-spec-satisficing](w22-spec-satisficing/): Acceptable is not compliant: a task is a list of requirements, the agent must report each implementation choice with its reason and then check it against every requirement (on a fixture label) before commit, so a choice that drops a requirement is refused even when the agent calls its reason acceptable, an unreported commit is refused, and a later self-correction that retains the dropping choice still fails; agrees with an independent backward-scan oracle on every fixture and exhaustively on short traces (Top method sketch of [arXiv 2611.16289](https://arxiv.org/abs/2611.16289); not a reproduction)
- [w22-revision-selectivity](w22-revision-selectivity/): Prestige is not selectivity: on frozen synthetic items whose second pass varies only the revision context (neutral, anonymous disagreement, expert-labeled disagreement) with the same argument text, a stdlib prestige-blind policy gives the same revise/retain decision whatever the source label, and a selectivity audit scores neutral apart from disagreement and reports "helped" only when wrong-initial reversals clear a declared fixture threshold over correct-initial reversals, never from reversal counts alone; agrees with an independent oracle on every fixture (Top method sketch of [arXiv 2611.16694](https://arxiv.org/abs/2611.16694); not a reproduction)
