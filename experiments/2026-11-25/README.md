# experiments/2026-11-25

- [mb-error-propagation-trace](mb-error-propagation-trace/): a green final answer can hide an error that passed from one agent to the next: on synthetic chains of deterministic agents with a known reference value at every hop, an outcome-only arm scores just the final answer, while a per-hop arm records each hop's error and classifies it as introduced, amplified, attenuated, corrected or clean; an error that reaches the end fails both, an error a later rechecking agent corrects passes the outcome-only arm but is traced as present and then corrected (never as no error), and a clean run passes with no hop error; class edges are declared and pinned (equal magnitude counts as amplified, an error equal to the tolerance is within it), an empty chain, NaN, Infinity, booleans and out-of-range values are DENY with exit 2, and no paper number is verified (method sketch of [arXiv 2611.31063](https://arxiv.org/abs/2611.31063); not a reproduction)
- [w34-mixed-index-crowds-unseen-tools](w34-mixed-index-crowds-unseen-tools/): shared tool experience mixed into the same index as tool descriptions crowds a held-out tool out of an equal budget of k = 3 distinct candidates, while a separate description index still offers it; three mandatory controls (empty pool, zero-overlap pool, gold already used), a leaky split reported in its own rows, a pre-registered flip at the fourth client, and bad input DENY with exit 2 (method sketch of [arXiv 2611.30034](https://arxiv.org/abs/2611.30034); not a reproduction)
