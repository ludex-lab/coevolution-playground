# Uptake E2 (hand-made fixture cover)

*Hand-made fixture for w32-record-manifest-presence. It mirrors the shape and the file names of the public E2 record
cover, which has no Corrections group; the prose here is new.*

## Files

| Group | Files | Note |
|---|---|---|
| Specification (verbatim) | `PREREG_uptake_e2.md` + `PREREG_PUBLISH_RECEIPT.json` | published before the run; the receipt carries the ordering evidence |
| Verdict | `VERDICT_uptake_e2.md` | priors scored |
| Instruments | `driver_uptake_e2.py`, `analysis_uptake_e2.py`, `test_uptake_e2_units.py` | analyzer fixed in advance |
| Data as run | `e2_battery.jsonl` (48 runs), `e2_pool.json`, `e2_result.json`, `e2_gate_battery.json`, `e2_drift_restamp.json`, `e2_telemetry.jsonl`, `e2_selftest_agy.json` | the raw run files |
